# 全站 UI 重设计需求

## 日期
2026-10-13

## 核心诉求
- 希望网站更有"人做的"感觉，而不是 AI 生成的机械感
- 更好看、更简洁实用
- 教练操作要简单：方便布置任务，发送训练计划给队员（支持指定队员/指定时间）
- 队员能很快写好反馈并提交给教练

## 确认的设计方向

### 视觉风格
- **主基调**: 暖色中性调（Training 主题为基础），走 Notion/Linear 那种干净清爽路线
- 保留主题切换功能，但三套主题都需要重新调优

### 需要解决的"AI 感"问题
1. ✅ 太多发光效果 (glow/shadow)、渐变色、玻璃拟态 (glassmorphism)，看起来像科幻 UI
2. ✅ 信息太密集，每个面板都塞满内容，缺乏留白和呼吸感
3. ✅ 排版太规整/机械，所有组件都是方方正正的卡片堆叠，缺少变化
4. ✅ 所有上述问题都有

### 教练 Dashboard 布局
- **决定**: 改为两栏布局
  - 左边：今日核心操作（快捷创建计划 + 发通知）
  - 右边：队伍概览（队员状态 + 反馈摘要）

### 教练端导航
- **决定**: 保持侧边栏但简化为图标+文字的干净列表，去掉折叠子菜单，去掉发光效果

### 队员端布局
- **决定**: 保留四个 Tab（训练、反馈、成就、个人），但重新设计每个 Tab 的内容布局，减少冗余

### 训练计划布置方式
- **决定**: 两种方式都保留（周计划 + 单次布置），让教练自己选择

### 设备优先级
- **决定**: 手机端和电脑端均衡考虑（家长可能手机打开，也有人电脑操作）
