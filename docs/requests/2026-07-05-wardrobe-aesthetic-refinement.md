# 2026-07-05 衣橱SVG美化与登录/同步可用性校验需求

## 需求背景
用户提出当前的“衣橱”（装扮功能）采用简单的几何图形（三角形、长方形）拼接，视觉效果不佳，不符合正常审美。需要将其重构为更加圆润、美观、有质感的SVG设计。
同时，用户要求确保队员端与教练端的数据同步、各项功能流程顺畅，包括队员填写训练反馈以及教练发布训练任务的可用性。

## 具体要求
1. **衣橱装扮组件美化**：
   - 彻底摆脱粗糙的直角矩形、三角形拼接，采用 `rx` / `ry` 属性或高级贝塞尔曲线 `path` 来绘制圆润、流线型的衣服、发型、帽子、脸型和配饰。
   - 为 SVG 装扮元素添加质感渐变（`<linearGradient>` / `<radialGradient>`）及立体阴影效果（`<filter>` 阴影或双层叠加描边），使装扮呈现现代插画级的拟物/扁平渐变风格（类似多邻国或百词斩的Q版美学）。
2. **两端登录与同步流程校验**：
   - 确保队员端和教练端之间的数据库同步无误（分班、XP、装备状态、反馈数据等）。
   - 实地自测教练发布训练计划 -> 队员端实时可见并能填写反馈 -> 教练端实时可见反馈的完整闭环。
   - 确保登录和路由跳转顺畅，无 404 或死循环重定向。
