# 2026-09-08 UI/UX 体验重构与系统精简需求

## 需求背景
随着项目重新接手与全面审视，现有系统存在诸多历史遗留与AI生成感明显的冗余设计：
1. **老旧衣橱与换装系统**：缺乏真实素材，使用临时占位图标与生硬的绿色高对比度边框（百词斩风格），体验粗糙、功能残缺。
2. **过于繁复且AI感强烈的背景系统**：14种背景渐变轮播、火花与星星粒子特效、光斑动画，视觉干扰严重且缺乏真实自然的质感。
3. **泳池大屏模式（Poolside）冗余**：用户实际使用场景为在家使用手机或笔记本电脑，泳池边无法实际操作电脑，大屏模式不符合实际痛点需求。
4. **双语系统复杂度**：当前团队为中文学校游泳队，全员使用中文，双语字典（25KB）及切换逻辑徒增维护负担。
5. **功能冗余**：单次快速训练（Quick Plan）与周训练计划（Weekly Plan）严重重叠，导航项过多（移动端多达12个项目）。
6. **AI生硬感与自然亲和力**：现有界面充斥大量营销感强的标语（如 "Next-Gen Swim Platform" 等）及千篇一律的暗黑科技风渐变，缺乏真实游泳运动的清爽自然感与人文温度。

## 目标与核心设计决策（经 /grill-me 确认）

### 1. 视觉体系与主题风格重构
- **拒绝 AI 生成感**：转向自然、舒适、人文的现代界面设计。
- **三大精选主题（Cohesive Themes）**，提供给教练和队员无缝切换：
  1. **Poolside（清新水感）**：明亮纯净，以柔和水蓝、微白、通透磨砂为主，清晨与日光泳池质感。
  2. **Competition（竞技深邃）**：专业沉稳，以深海青黑、冷白与能量高亮为主，专注专业训练。
  3. **Training（温润中性）**：温暖舒适，柔和暖灰、自然青绿与大地色调，居家查阅极度护眼舒适。
- **彻底移除旧背景杂音**：废除14种背景轮换、粒子动画（`BackgroundParticles`）、背景选择器（`BackgroundPicker`）与生硬的光斑动画。

### 2. 游戏化与激励系统重构
- **保留核心成长机制**：保留 XP 经验值、等级系统（Level）、连续训练打卡记录（Streak）、最佳成绩（PB）与里程碑。
- **彻底移除虚拟衣橱与换装（Wardrobe / Shop / Closet / Buddy）**：移除 `ShopAndCloset`、`AvatarRenderer`、`RoomEnvironmentRenderer` 及相关冗余 UI，降低系统冗杂度，专注纯粹的训练成长反馈。

### 3. 登录与入口体验
- **移除公关营销首页**：访问 `/` 直接重定向至统一登录入口 `/login`。
- **一体化登录页面**：单页面集成角色切换（教练 / 队员），移动端触控友好，界面干净纯粹。

### 4. 教练端体验优化（移动端优先）
- **导航精简**：采用底部标签栏（Tab Bar，类似微信/钉钉体验，4-5个核心区：首页概览、周训练计划、队员名单、更多）。
- **移除冗余功能**：完全移除 Quick Plan，统一以 Weekly Plan（周计划）为核心工作流。
- **保留核心高频模块**：周计划管理、每日考勤签到、队员档案与状态、训练反馈查阅与回复、比赛管理、伤病追踪、设置。

### 5. 队员端体验优化（模块化重构）
- **解耦 900+ 行庞大巨石组件**：重构 `workout/page.tsx` 为四大清晰模块：
  1. **今日训练（Training）**：查看当天及本周训练内容、教练批注、动作要点。
  2. **训练反馈（Feedback）**：提交 RPE 疲劳度、酸痛感、心得反思，查看教练暖心回复。
  3. **成绩与荣誉（Achievements）**：清晰的 XP 进度条、等级徽章、连续打卡天数、个人最好成绩（PB）。
  4. **个人中心（Profile）**：个人基础档案、伤病状态、主题偏好设置。

### 6. 泳池模式下线
- 彻底移除 `/poolside` 大屏模式，聚焦家庭端手机/电脑的流畅查阅与操作。

### 7. 纯中文极简语言策略
- 移除多语言切换与无用字典代码，全面统一为地道、自然、充满鼓励的中文文案。
