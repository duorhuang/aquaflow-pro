# 2026-10-16 全站端到端业务闭环核验与全中文本地化规范

## 需求背景
用户通过 `/goal` 提出全站深度核验与打磨目标，重点关注以下四大核心维度：
1. **教练与队员双端登录机制核验**：
   - 教练端登录（密码验证、Session Cookie、权限中间件判定、跳转）。
   - 队员端登录（账号/姓名选择、密码验证、防死循环恢复、Session 与 ID 绑定）。
2. **教练与队员双向数据协同通路（业务闭环）**：
   - 教练发布周计划/训练计划/公告/指定队员及组别 -> 队员端即时拉取与清晰呈现。
   - 队员提交每日训练反馈/RPE疲劳度/自查出勤 -> 教练端看板与反馈中心即刻接收、审阅与回复。
3. **全站极致纯中文本地化（100% Chinese Experience）**：
   - 杜绝任何夹杂英文的界面遗留（包括按钮、状态徽章、表单占位符、图表标签、Toast 提示、空状态与弹窗）。
   - 游泳专业术语（自由泳、仰泳、蛙泳、蝶泳、混合泳、包干、包干时间、打腿、划手、分解）准确地道。
4. **全功能稳健运行与部署闭环**：
   - 确保全站语法与功能无 Bug，构建无异常，代码提交并同步至 GitHub 与 Cloudflare 生产环境。
